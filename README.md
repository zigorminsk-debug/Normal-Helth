# ZI-Normal-Helth — сон, питание и активность

Небольшое офлайн-приложение для Android, которое помогает соблюдать ежедневный режим без регистрации и подключения к интернету.

## Что уже работает

- **Сон и отдых:** время подъёма задаётся пользователем; время отбоя автоматически рассчитывается из желаемой длительности сна. Есть утреннее уведомление с рекомендациями, пошаговый разбор упражнения на картинках с автоматической сменой каждые 8 секунд и голосовым пояснением через системный Text-to-Speech, собственная офлайн 3D-анимация. При наличии интернета можно открыть исходное видео внутри приложения; расписание восстанавливается после перезагрузки телефона.
- **Питание:** отдельные напоминания о завтраке, обеде и ужине. Для каждого приёма пищи есть варианты блюд белорусской домашней кухни и чекбоксы. Обед собирается по компонентам: основное блюдо, салат, суп по желанию и напиток. Кнопка «Сформировать меню» выбирает варианты, которые не повторялись в последних днях, и сохраняет историю на устройстве.
- **Активность:** напоминания о коротких разминках в рабочее время и о прогулках. Можно выбрать интервал 45, 60 или 90 минут, а также цель — 2 или 3 прогулки. Выполненное отмечается на экране дня.
- **Уведомления:** локальные Android-уведомления без сервера. Приложение просит разрешение на уведомления на Android 13+ и умеет работать с точными будильниками, если пользователь разрешит их в настройках.

## Сборка APK

Откройте корень проекта в Android Studio (Hedgehog или новее), дождитесь синхронизации Gradle и запускайте именно release-сборку, чтобы сохранить совместимость подписи:

- `Build` → `Generate Signed Bundle / APK` — подписанный APK для установки на устройство;
- или из терминала `gradle assembleRelease`.

Файл появится в `app/build/outputs/apk/release/app-release.apk`.

## Постоянная подпись приложения

Для проекта создан постоянный ключ Android-подписи в формате PKCS#12: `signing/normal-helth-release.p12`. Параметры находятся в `keystore.properties`, а release-сборка настроена использовать этот же ключ каждый раз.

Чтобы собрать подписанную версию, выполните:

```bash
gradle assembleRelease
```

APK появится в `app/build/outputs/apk/release/app-release.apk`. Не удаляйте и не теряйте файл keystore: будущие обновления Android должны быть подписаны тем же ключом, иначе они не установятся поверх текущей версии. Сделайте резервную копию keystore и `keystore.properties` в защищённом месте. Для реального публичного продукта храните ключ в закрытом хранилище или GitHub Actions Secret; ключ в этом учебном репозитории предназначен для воспроизводимой сборки APK.

Проект не использует AndroidX, Kotlin или сторонние библиотеки: для UI и уведомлений достаточно Android SDK. Минимальная версия Android — 6.0 (API 23).
