# Режим — сон, питание и активность

Небольшое офлайн-приложение для Android, которое помогает соблюдать ежедневный режим без регистрации и подключения к интернету.

## Что уже работает

- **Сон и отдых:** время подъёма задаётся пользователем; время отбоя автоматически рассчитывается из желаемой длительности сна. Есть утреннее уведомление с рекомендациями и восстановление расписания после перезагрузки телефона.
- **Питание:** отдельные напоминания о завтраке, обеде и ужине. Для каждого приёма пищи есть варианты блюд белорусской домашней кухни и чекбоксы. Кнопка «Сформировать меню» выбирает варианты, которые не повторялись в последних днях, и сохраняет историю на устройстве.
- **Активность:** напоминания о коротких разминках в рабочее время и о прогулках. Можно выбрать интервал 45, 60 или 90 минут, а также цель — 2 или 3 прогулки. Выполненное отмечается на экране дня.
- **Уведомления:** локальные Android-уведомления без сервера. Приложение просит разрешение на уведомления на Android 13+ и умеет работать с точными будильниками, если пользователь разрешит их в настройках.

## Сборка APK

Откройте корень проекта в Android Studio (Hedgehog или новее), дождитесь синхронизации Gradle и выберите:

- `Build` → `Build APK(s)` — отладочный APK;
- или `Build` → `Generate Signed Bundle / APK` — подписанный APK для установки на устройство.

Собранный отладочный файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

Проект не использует AndroidX, Kotlin или сторонние библиотеки: для UI и уведомлений достаточно Android SDK. Минимальная версия Android — 6.0 (API 23).
