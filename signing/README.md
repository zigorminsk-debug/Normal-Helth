# Ключ подписи

Файл `normal-helth-release.p12` создан для постоянной подписи Android-релизов приложения. Release-сборка использует его на каждом запуске.

- alias: `normalhelth`
- формат: PKCS#12
- срок сертификата: 17.09.2026–09.09.2056
- SHA-256 сертификата: `9F:BD:1A:B3:1C:6B:39:4A:27:31:F6:6A:8B:A3:67:C5:36:27:03:1B:56:12:8E:DE:32:46:EA:07:80:47:26:D6`

Сделайте резервную копию `normal-helth-release.p12` и `keystore.properties` в защищённом месте. Для production-приложения вынесите ключ из открытого репозитория в закрытое хранилище.
